## About the Project

The **Weekly Report Submitter** simplifies organizational progress tracking by offering state-managed dashboards for team members to log performance metrics alongside dedicated compliance grids for management. This project follows the **MVC (Model-View-Controller)** architecture on the backend to ensure clean code separation, maximizing scalability, testability, and enterprise-grade maintainability.



## Technologies Used

- **Frontend**: React.js (Vite), Tailwind CSS, Framer Motion, Recharts, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose ODM)
- **AI Core**: Google Gemini 2.5 Flash API
- **Mailing**: Nodemailer (Gmail SMTP)
